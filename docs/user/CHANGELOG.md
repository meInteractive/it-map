## 22.10.2026 — ручное заполнение пустых уровней

По запросу владельца SQL0081 однократно заполняет24 наблюдённых пустых уровня вакансий с датой публикации16–22 октября (fallback загрузка/создание), используя только Middle/Senior/Lead/Head. Описания, роли, релевантность, письма и личные состояния не пересчитываются. Существующая provenance помечает уровень как ручной. Docs218/82 миграции; API22.10/backup38/rating5 прежние.

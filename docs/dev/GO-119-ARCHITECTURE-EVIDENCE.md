## 3. Проверки и интерпретация результатов

- **Непосредственно подтверждённый CI:** PR [#496](https://github.com/meInteractive/it-map/pull/496), head `51ffa71dba0d88e8431efde9b54a55b67c28663a`, прошёл **4 из 4** GitHub Actions workflow: Go/public safety, disposable MariaDB, неподдерживаемая MariaDB 10.3.32 и Worker build artifact. Merge в `main` — `2e67027363534b54b16295fe541dfdb4b968e693`. Это доказательство **этого PR и его CI**, не текущих служб/внешних Google API.
- **GO-431 P0:** [#495](https://github.com/meInteractive/it-map/pull/495) (merged) проверяет отдельно остановку до попытки, после attempt до `Billing.Run` и во время уже начатого запроса, с сохранением результата/известного settlement в синтетической MariaDB. Сценарий SIGKILL с неизвестным фактом provider billing остаётся консервативным: `unknown` нельзя обнулить.
- **Новая обязательная фронтенд-проверка:** `npm run typecheck:web` [GO-113](GO-113-TYPESCRIPT-CI.md), `npm run format:check` [GO-114](GO-114-FORMATTING.md). Браузерные тесты постепенно разбиты на независимые Playwright-сценарии (GO-117). Прежнее утверждение «TypeScript не включён в CI» устарело.
- **Разделение релизов:** [`publish.yml`](../../.github/workflows/publish.yml) пакует **API + React**, [`worker-artifact.yml`](../../.github/workflows/worker-artifact.yml) собирает **Worker/Recovery**. Получение Worker artifact не означает установку Worker. [GO-447](../../tasks/GO-447-WORKER-DEPLOY-RESTART.md) / [Issue #472](https://github.com/meInteractive/it-map/issues/472) — отдельный проект совместной доставки, проверяемого drain/restart/rollback.
- **API migration gates сохраняются:** [`config.ValidateEnvironment`](../../internal/config/config.go) отвергает `APP_ENV=production` в HTTP binary, `GET /health/ready` отвечает 503 даже при доступной БД. Worker отдельно допускает production-профиль при строгих флагах; не переносить правила одного процесса на другой.

## 4. Что проверять перед следующей разработкой

1. Сверить последний `main`, merge/CI и наличие конкретной реализации, а не только её design/issue.
2. Отдельно выяснить (по разрешённой read-only диагностике) установленные SHA Go API и Worker; **не запускать второй consumer** и не выполнять платных операций ради проверки.
3. При изменениях платных операций сохранять разделение `confirmed` / `unknown` / `reserved`, не выдавать локальный импорт или API response за подтверждённую стоимость.
4. Для календаря проводить реальный OAuth/sync только с личным разрешением и тестовой учётной записью.
5. Руководствоваться [`AGENTS.md`](../../AGENTS.md), [реестром задач](../../tasks/README.md), [архитектурой](ARCHITECTURE.md), [актуальным handoff](handoff/README.md); завершённая работа ChatGPT без ревью Codex имеет статус **«к проверке»**.

**Публичная граница:** никаких реальных серверных адресов, секретов, приватных provider receipts, backup, SQL-дампов или пользовательских резюме в этом документе.

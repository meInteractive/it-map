# GO-369: SQL-снимок классификации кандидата

ReadCandidateTitleInput в существующей транзакции проверяет серверного владельца, выбранный источник, доступность компании или агентства и актуальность заголовка. Затем читает активные корневые роли и решения JEV, соответствующие текущим заголовку, ревизии и версии промпта. Устаревшее решение не подставляется вместо актуального; ошибочные решения приводят к ошибке.

Результат имеет отдельный тип частичного снимка: он не содержит полный текст, результаты структурирования и назначения ролей. Подключение к CandidateHandoff и запуск worker не выполнены. Интеграционный тест работает только на одноразовой MariaDB в GitHub CI и сравнивает решения с синтетическими source-сценариями.

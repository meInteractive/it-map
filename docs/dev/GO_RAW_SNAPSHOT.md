# GO-362: полный исходный текст вакансии

`AssembleRawSnapshot` восстанавливает встроенный Markdown либо последовательно пронумерованные части. Перед дальнейшей обработкой проверяются целостный UTF-8 и сохранённый SHA-256; отсутствие, пропуск, перестановка или изменение части вызывают ошибку. Текст сохраняется целиком, никакого усечения до вызова модели нет.

`RabotaBodyPresent` воспроизводит исходную проверку содержательной карточки rabota.ru: заголовок, ссылки и блоки «Смотрите также» не заменяют текст обязанностей. Используются те же признаки, граница250 UTF-16 units и правила разрыва строк. 16 actual source frames проверяют русские и английские описания, emoji, ссылки, NBSP и Unicode; mock tests отдельно покрывают целостность частей.

Это pure слой, который будет использован SQL repository полного текста и extraction в GO-363. Существующие исходные таблицы не меняются; worker, платные провайдеры и сервер не запускаются этой веткой.

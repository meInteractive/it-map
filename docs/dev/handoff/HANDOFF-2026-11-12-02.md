# Передача 12.11.2026: воспроизводимый доступ к серверу

Продолжение [передачи GO-431](HANDOFF-2026-11-12.md). По поручению владельца
обновлён [навык настройки сервера](../../../.agents/skills/itmap-server-setup/SKILL.md).

Навык перечисляет необходимые приватные параметры без их значений, разделяет
проверки CONNECT, host key и SSH-входа, описывает проверку существующего ключа
в workspace, работу через sidecar-прокси и точечное снятие срока scheduler.
Отдельно закреплена передача параметров только внутренним текстом чата, без
приватных ключей, токенов и паролей. В публичную документацию их не переносить.

В этой сессии подтверждены работа VPN, CONNECT, совпадение независимо
подтверждённого host key и административный SSH-вход. По ранее выданному
разрешению снята только календарная блокировка установленного scheduler tick;
резервная копия сохранена на сервере, синтетические проверки и проверка diff
прошли. Расписание и остальные предохранители сохранены. Production MariaDB
не изменялась, ручные платные запуски не выполнялись. Результат следующего
естественного срабатывания на момент фиксации не проверен; предыдущий запуск
вернул `partial`, причина отдельно не исследована. Это не подтверждение
полной исправности парсера. Операционные параметры и точные пути резервной
копии остаются во внутреннем тексте чата.

Этот PR меняет только документацию; merge выполняет владелец. Статусы CI,
других PR и production нужно заново проверять перед продолжением.

## Изменение

[ТЗ GO-448](../../../tasks/GO-448-COMPANY-FAVORITES-TRISTATE.md).

- `frontend/features/companies/Filters.tsx`: вместо `favoriteOnly`
  выбран `favorites: 'favorites' | 'notFavorites' | 'all'`.
  `RankFilter` больше не содержит чекбокс избранного.
  Новый `FavoriteFilter` — отдельный `FilterMenu`, внутри три radio.
  `matchesEntity` применяется к списку и map, без дублирования логики.
- `frontend/Application.tsx`: общий controlled фильтр в header.
  Доступен в map, списке компаний/агентств и списке вакансий
  компаний/агентств (там прежний checkbox тоже действовал через
  `matchesEntity`). В каналах, где он не влияет на выборку,
  кнопка скрыта. «Избранное» для **самих вакансий** остаётся
  самостоятельным чекбоксом «Признаки вакансии».
- Старый storage key `moscow-it-employers:rank-filter:v1` читается:
  `version:1,favoriteOnly:true` → `favorites`, иначе `all`.
  После чтения сохраняется `version:2` в том же ключе.
- `frontend/styles/app.css`: отдельная кнопка/меню, поведение
  desktop/mobile; Escape/blur/outside поддерживает общий `FilterMenu`.
- Backend, CRM mutation, API и схема БД не меняются. Пользователь
  открывает карточку не избранной компании и нажимает существующую
  звёздочку, что обновляет список/карту после успешного cache invalidation.

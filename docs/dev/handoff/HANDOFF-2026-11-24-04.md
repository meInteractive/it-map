# IT Map — портфолио кандидата, 24.11.2026

В разделе «Резюме» появился отдельный Markdown-редактор портфолио с ограничением 20 000 символов. Поле сохраняется через личный /api/profile/portfolio, с независимой версией. Хранилище использует запись с зарезервированным префиксом в user_profiles. Это сохраняет действующий формат резервных копий и позволяет обойтись без DDL. Префикс зарезервирован для внутренних записей, логины проекта используют фиксированный набор имён.

При генерации сопроводительного письма текущему системному промту добавляется инструкция по выбору проекта через его название, предметную область и технические детали, затем по использованию фактов из описания. Текст портфолио передаётся как отдельное поле данных и входит в снимок генерации. Сохранённое резюме не меняется при сохранении портфолио.

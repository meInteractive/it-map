## 3. Статусы и способ проверки
- В выполненной ChatGPT-части без независимой приёмки Codex ставить **«к проверке»**, но не `[x]`. Для большого эпика — **«частично реализовано — к проверке»**; непокрытые критерии и production-gates не закрывать.
- По GitHub-пользователю `meInteractive` и префиксу `codex/` нельзя надёжно идентифицировать исполнителя. Сопоставлять с handoff и пользовательской перепиской, спорные PR отмечать «исполнитель не установлен».
- Для stacked PR различать «merged в ветку» и «доставлен в main». Закрытые без merge PR не учитывать как выполненную реализацию.
- CI на прошлом SHA не переносить на текущую ветку. До ручной приёмки проверить актуальные PR, code review и специальные synthetic/браузерные тесты.
- **Публичный handoff не содержит** адресов сервера, credentials, tokens, provider account data, backup, реальные резюме и приватные JSON; закрытые операционные подробности остаются в пользовательском чате.

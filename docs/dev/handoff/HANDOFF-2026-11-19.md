4. **GO-293/GO-304/GO-436** — фактические пропуски HH при прежних интервалах 7 дней и окне 3 дня, происхождение дат воронки, уникальные новые вакансии и историческая аномалия 61 требуют независимой read-only проверки.

## 5. Правила безопасности и методика продолжения

- **Нельзя без нового согласования владельца:** live SQL/DDL/restore/migration, изменение production ledger/бюджетов, новые платные AI/Apify/Firecrawl запросы, ручной HH/backfill, серверные секреты/config, изменение systemd и timеr, restart/deploy Worker, запуск второго consumer, автоматический merge.
- Для кода — synthetic unit/Go race, disposable MariaDB, front/Node/Playwright по затронутому сценарию; проверять точный head SHA CI и отсутствие `SKIP`. Если тест недоступен, писать `не запускался`.
- Для задач, реализованных ChatGPT без документированного ревью Codex, **«к проверке»** (или **«частично реализовано — к проверке»** для незавершённых крупных задач). Не менять `[ ]` на `[x]` до завершения критериев и независимого QA, даже после merge.
- Отличать **provider confirmed cost**, **reserved USD** и **unknown cost**; отсутствие подтверждённой суммы не значит нулевой расход. Candidate stage/receipt, созданная впервые карточка и импорт существующей вакансии — разные метрики.
- Весь приватный серверный контекст передаётся только в чате пользователя; новая передача не содержит закрытых значений и не является разрешением на подключение.

# IT Map — ручная релевантность, 24.11.2026

GO-018, частично реализовано — к проверке. После #565 автоматический расчёт и ручная кнопка оставались отдельными путями. Ручной POST /api/vacancies/{id}/relevance теперь вызывает Go API, использует сохранённое резюме текущего пользователя, промт и модель, проверяет актуальность данных и обновляет личную оценку. При неопределённом исходе повтор для тех же входных данных ограничен двумя минутами.

Проверка на одноразовой MariaDB с подставным ответом провайдера покрывает HTTP-ответ, запись оценки и изоляцию между пользователями. Рабочий провайдер и production требуют отдельной приёмки.

# IT Map — несколько резюме, 24.11.2026

GO-452 взята в реализацию по решению владельца. Go API поддерживает до трёх именованных резюме, одно основное и общее Markdown-портфолио. Существующий текст остаётся первым резюме. В письме можно сменить резюме для конкретной генерации, а в форме нового отклика выбор сохраняется вместе с названием на момент создания.

Хранение использует зарезервированные ключи в действующей таблице профилей и совместимо с действующей схемой резервной копии. Список резюме сохраняется транзакционно с проверкой версий. Предыдущие вызовы API без выбора поддерживаются. Проверки используют синтетические данные и подставные ответы модели.

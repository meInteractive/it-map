# IT Map — вакансии в карточке компании, 24.11.2026

GO-011, частично реализовано. Вкладка «Подходящие вакансии» использует GET /api/vacancies?company=… . В Go API этот запрос попадал в заглушку. Маршрут теперь использует существующее чтение вакансий компании или агентства и возвращает справочник связанных работодателей. Личные поля берутся из сессии.

Проверка добавлена в существующий HTTP-тест MariaDB с синтетическими данными. Она проверяет доступ по сессии, код 404 для отсутствующей компании, полные поля вакансии и изоляцию релевантности. Проверка вкладки на рабочем сайте остаётся частью приёмки после деплоя Go API.

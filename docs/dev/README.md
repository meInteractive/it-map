# Документация разработчика

Внутренние материалы разработки, переноса на Go и проверки совместимости. **Главная архитектурная точка входа актуализирована 19.11.2026** по `main=2e670273`: теперь это два основных Go runtime (API + отдельный Worker) с общей MariaDB, а не один HTTP-процесс с циклическим парсером.
Пользовательские руководства и инструкции установки находятся в [docs/user](../user/README.md).

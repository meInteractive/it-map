# Отложенный фильтр HH по названиям

05.11.2026 пользователь решил сначала реализовать фильтрацию только по профессиональным ролям HH и попросил сохранить вариант поиска по названиям на будущее. Этот документ — черновик решения; он не включает фильтр и не меняет действующие запросы.

Ранее исследован временный список конкретных названий для крупной роли IT Manager вместо одиночных широких слов `менеджер*`, `директор*`, `manager`, `head` и т. п. Вариант словаря:

```text
Development Manager

IT Project Manager
Project Manager

Руководитель проектов
Technical Project Manager

Platform Product Manager
Тимлид

CTO
CPO
CIO
```

Временная реализация строила HH-выражение `NAME:("…" OR "…")` в `internal/parser/hh_listing_data.go` и проверяла синтетические примеры и состав `startUrl` перед Actor. Этот локальный эксперимент отменён при смене приоритета и не попал в Git; список и подход сохранены здесь. Перечень нужно дополнительно проверить и согласовать с действующей классификацией: `Project Manager` и «Руководитель проектов» не обязательно относятся к IT, а отсутствие синонимов может отсеять подходящие вакансии. Синтетическое буквальное сравнение не подтверждает морфологию или поведение поиска HH.

Перед возможным внедрением определить отдельно для каждой крупной роли редактируемый список названий и его связь с классификацией; уточнить, должен ли он объединяться или пересекаться с HH `professional_role`, и проверить семантику на реальном Actor. Нужны ревизии настроек, сохранение input старых оплаченных Actor и защита от незаметных повторных платных запусков. Не включать этот фильтр в GO-423–GO-425 без нового решения пользователя.

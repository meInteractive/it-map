# GO-371: SQL-снимок извлечения вакансии

ReadCandidateExtractionInput собирает проверенные классификацию и полный текст; для свежего текста читает текущие настройки извлечения и результат, совместимый с ID исходного снимка, настройками, версией промпта и схемой. Кеш повторно проверяется и нормализуется. Устаревший промпт или настройки не используют старый результат; повреждённые и неоднозначные данные останавливают обработку.

Если классификация не готова, текст отсутствует или требуется обновление, результат извлечения не выбирается. Это частичный снимок: роли, полный SQL-планировщик и работающий обработчик задач подключаются отдельно. Тесты источника и кеша выполняются в изолированной MariaDB GitHub CI; запросов к реальным провайдерам нет.

## Go: задачи CRM — частичная реализация GO-014 / GO-033

- `POST /api/tasks` создаёт задачу с текущим пользователем, компанией, типом, заметкой и UTC-сроком. Проверяет существование компании в `app_catalog`, связь вакансии с компанией, лимиты и типы задач. Сохраняет `company_crm` и `company_tasks` одной транзакцией и возвращает `{ok:true,taskId,calendarSync:{status:"not_connected"}}` с HTTP 201.
- `PUT /api/tasks/{id}` теперь принимает **ровно одно** поле `dueAt` или `completed`. Новый обработчик строгий к структуре JSON, авторизации и происхождению запроса. Дата в формате ISO 8601 переводится в UTC с тремя миллисекундными разрядами, как `Date.toISOString()` в JavaScript.
- При существующем `google_calendar_user_connection` для пользователя создание/перенос срока **отклоняется с HTTP 409 без записи**. Для переноса срока дополнительно проверяются поля привязки Google Calendar конкретной задачи. Это сознательная временная защита: Go-клиент календаря ещё не реализован, поэтому незаметно рассинхронизировать события нельзя.
- Переключение `completed` продолжает работать, включая старые тесты. Операции строго ограничены авторизованным пользователем.

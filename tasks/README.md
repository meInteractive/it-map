**Идентификаторы:** `GO-NNN` постоянные, никогда не переиспользуются; GO-001…GO-028 соответствуют исходным `1.1.01…1.1.28`; GO-029…GO-046 — выделенные малые задачи. GO-101+, GO-201+, GO-301+ зарезервированы за спринтами 1.2, 1.3 и 1.4. При новом дроблении брать следующий свободный номер в нужном диапазоне, сохранять номер исходной задачи и объяснять зависимость.

**Статусы:** `[x]` только при завершённых критериях и проверенном результате; `[ ]` означает не принято целиком. Наличие Go-кода, успешного `go test` или упоминания в старом отчёте не закрывает задачу, если она требует staging, реальной MariaDB или end-to-end теста. Коммиты в незакрытой задаче отражают подтверждённый **частичный** код. Если тест не выполнялся, прямо писать «не запускался». GitHub PR и ручную приёмку фиксировать в самой задаче, не удалять историю.

**Цикл Codex:** выбрать GO-NNN → прочитать `AGENTS.md` и относящиеся исходники → проверить зависимости → отдельная ветка → реализация → тесты → PR (без merge) → обновить одну задачу со ссылкой на коммит/PR, тестами и ограничениями → остановиться. Без нового поручения не брать другие крупные задачи.

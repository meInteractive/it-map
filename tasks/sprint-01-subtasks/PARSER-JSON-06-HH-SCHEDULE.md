# GO-439 / S11-DIAG-06 — безопасный JSON расписания HH

**Поручение владельца:** 10.11.2026. В раздел «Парсер → Диагностика → Когда HH проверят снова?» добавить кнопку «Копировать JSON», предоставляющую пригодный для анализа текущий снимок без ручного переписывания цифр.

**Область:** только React, whitelist общего сериализатора и синтетические тесты. Используется существующий GET `/api/scheduler/hh-schedule`. Нет DDL, миграций, оплачиваемых вызовов, изменения worker, бюджета, таймеров или рабочего расписания.

**Критерии:** экспорт версии 1 включает время снимка, область, правила, `configured/due/waiting/active`, охват 24/48 часов, отсутствие даты, очередь и все агрегированные причины ожидания с `oldestPendingAt`. Отсутствующие данные сохраняются как неизвестные, не 0. Кнопка использует cached GET, проверяет административный сеанс и не копирует приватные поля, job/company/provider ID, URL, payload или credential. Ошибка или некорректный ответ блокируют копирование.

**Тесты:** `node scripts/test-parser-statistics-debug-json.mjs`, `node scripts/test-parser-hh-schedule-ui.mjs`, `node scripts/check-api-coverage.mjs`, `npm run format:check`, `npm run typecheck:web`, `npm run build:web`, обязательный PR CI. Проверить отсутствие дополнительных запросов и неизменность GET-контракта. Ручной merge только после зелёных проверок на точном SHA.

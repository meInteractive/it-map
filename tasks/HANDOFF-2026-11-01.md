## Ограничения и сервер

Не печатать .env, DSN, секреты, приватные ключи, реальные данные или ciphertext. Не менять реальные БД/DDL/production, не включать worker/платные вызовы без отдельного поручения. Не сливать PR автоматически.

Main имеет ранее разрешённый автодеплой на временный staging: пользовательские merge могут выкладывать сайт. Production cutover и импорт реальных данных отдельно. Здесь сервер не менялся. Исторические указания «деплой полностью выключен» в старых документах не считать текущим статусом.

Для Codex-доступа к серверу есть репозиторный skill «Настройка сервера»: VPN работает через сервис среды/внутренний прокси, отсутствие tailscale0/CLI в контейнере ничего не доказывает. Для GitHub Actions выбран публичный SSH без VPN. Не воспроизводить старые ключи и не переносить секреты в handoff. Перед новой серверной задачей перечитать skill и текущую политику среды.
